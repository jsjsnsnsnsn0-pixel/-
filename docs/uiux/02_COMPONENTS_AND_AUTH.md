
# Stage 01 / 02 — Follow-up design evidence

UX-013 semantic 24dp stroke icons are now used for Home, Messages and My Account navigation in the isolated preview. Emoji, mosque and lamp decorations were removed from these three core navigation actions; the existing green/white/gold palette remains unchanged.

UX-014–UX-017 remain draft rules, not complete design deliverables: avoid oversized premium effects obscuring controls, document reduced-motion, standardize error/permission/loading copy, and preserve the owner's existing theme.

UX-018–UX-027 are represented by an isolated, clickable sign-in storyboard under the screen menu "تجربة الدخول · تصميم". It is not the real app login. Phone OTP uses a clearly marked demonstration code 123456 with no network or SMS. Email and password steps validate only the local sample fields; no account is created. Recovery, accessibility, device keyboard and offline parity need further QA.

The original TotiChat branch, user accounts, voice audio and monetary backend are not modified.
