# معاينة تحديث TotiChat

الرابط /review.html يعرض مكونات التطبيق الفعلية بعد التحديث مع بيانات تجريبية معزولة. لا تستخدم المعاينة حسابات أو أرصدة حقيقية ولا تنفذ اتصالات بقاعدة التطبيق.

شريط أدوات المعاينة يتيح التنقل بين الغرفة والرئيسية وأنا والبروفايل والإعدادات، وتبديل دور المستخدم وحالة CP. جميع تعديلات البيانات داخل المعاينة مؤقتة.

الموسيقى والصوت المباشر يحتاجان اختباراً على هاتفين في التطبيق الفعلي. المعاينة تعرض واجهتهما دون تسجيل أو بث صوت. تفاصيل التنفيذ محفوظة في AGREED_UPDATE_2026_10_06.md.
